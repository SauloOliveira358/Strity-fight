# STREATY FIGHT 2 • TURBO BRASIL (Strity Fight da Turma)

Jogo de luta 2D estilo **Street Fighter 2** em HTML5 Canvas + JavaScript puro + Web Audio API, com personagens da turma, vozes em português (PT-BR) e efeitos sonoros zueira.

## Personagens Jogáveis

1. **Saulo Oliveira** — *Soco do Shape*, *Bolacha Passatempo* e especial **Me Ajuda, Larissa!** + **Rajada de Passatempo**
2. **Thiago** — *Tapa de T.I.*, *Voadora de Palito* e especiais com a **Máquina Escavadeira**
3. **Stênio** — *Guidão na Cara*, *Rabetada de XRE* e especiais **Grau Monstro** e **Grau Longa Distância**
4. **Kamile** — Pesos de academia + **Chicote de Cabelo**
5. **Larissa** — **Chicotadas** e especial **Escravos Acorrentados** (Thiago e Saulo acorrentados)
6. **Alexandre** — **Cachaça Pirassununga 51** e especial **Quebrou a Placa de Vídeo (RTX)**
7. **Diogo** — Modo Hacker com ataque de **Claudinhos IA**

## Controles

- **P1:** `A` / `D` Mover (`2x` Dash!) • `W` Pular • `S` Defender • `F` Golpe 1 • `G` Golpe 2 • `H` Especial 1 • `J` Especial 2
- **P2 (Modo 2P):** `←` / `→` Mover (`2x` Dash!) • `↑` Pular • `↓` Defender • `K` Golpe 1 • `L` Golpe 2 • `P` Especial 1 • `O` Especial 2

## Como Jogar Localmente

Execute `JOGAR.bat` ou inicie um servidor HTTP estático na pasta do projeto:

```bash
python -m http.server 8765
```

Depois abra `http://localhost:8765/index.html` no navegador.
